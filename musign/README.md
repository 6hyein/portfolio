# musign / 뮤자인 지원용 포트폴리오

(주)뮤자인 웹퍼블리셔/프론트엔드 개발 공고(2026.11)에 맞춰 만든 폴더입니다.
저장소 루트의 기존 포트폴리오(index.html, js/script.js 등)는 건드리지 않았습니다.

## 주소

https://6hyein.github.io/portfolio/musign/works.html

## 파일

- `works.html` 작업 모음 페이지
- `css/works.css` 스타일
- `js/works-data.js` 작업 45개 데이터와 상세 설명 (작업을 고치거나 추가할 때는 이 파일만)
- `js/works-status.js` 링크 확인 결과 (캡처 프로그램이 만듦)
- `js/works.js` 화면 그리기와 애니메이션
- `images/works/` 캡처 이미지 (캡처 프로그램이 만듦)
- `tools/capture.mjs` 사이트 캡처 + 링크 확인 프로그램

## 사용한 것

- jQuery 3.7: 데이터로 화면 그리기, 필터, 상세 창, 복사 버튼
- GSAP 3.13 + ScrollTrigger: 인트로와 스크롤 애니메이션
- 꼬마 악마 캐릭터: 직접 그린 SVG

## 애니메이션 (js/works.js 번호와 같음)

1. 스크롤 진행 바
2. 인트로
   - 꼬마 악마가 위에서 떨어져 Y 를 밟고, H 로 튀어 간다. 튈 때 조금 커져 화면 쪽으로 다가오는 느낌 (발밑 그림자, 입체 명암)
   - H 에서 높이 솟았다가 쾅 내려찍으면 지진처럼 화면이 흔들리고, 글자가 한꺼번에 튀었다가 무너진다. 내려찍은 자리에서 잔금이 번진다
   - 악마가 무너진 글자 더미 위에 착지하면 발밑에 동그란 구멍이 생긴다
   - 공연하는 동안(약 3초)은 스크롤을 막는다 (휠, 터치, 키보드). 끝나면 '다시 세우기' 버튼이 나온다
   - 스크롤하지 않고 가만히 있으면 마우스 포인터 주변으로 동그라미가 퍼지며 Scroll 안내가 나온다 (터치 화면은 가운데)
   - 스크롤하면 악마가 구멍으로 빠지고, 구멍(clip-path 원)이 커지며 그 뒤의 소개와 숫자가 드러난다 (pin + scrub)
   - 마우스를 가까이 대면 글자가 밀려나며 기울어지고, 악마 눈동자가 마우스를 따라본다
3. 작업 45개 (참고: Inkwell, Tracing Art, David William Baum 포트폴리오)
   - 밝은 판이 둥근 카드처럼 올라오다가 화면을 꽉 채운다 (clip-path inset + round)
   - 카드 가로 세로 비율은 작업마다 다르다: 직접 고른 이미지는 원본 비율(4:3), PC 사이트는 가로로 넓게, 모바일 랜딩페이지는 세로로 길게
   - PC: 카드가 비스듬히 겹쳐 서 있고, 스크롤하면 한 장씩 넘어온다. 대표 작업 5장은 천천히, 나머지는 빠르게
   - 끝까지 넘기면 크기, 자리, 기울기가 제각각인 콜라주로 흩어진다. 대표 작업은 크게, 몇 장은 흰 액자
   - 위쪽 단계 표시(Selected / All works / Index), 위아래로 굴러가는 번호 카운터
   - 마우스: 유리 원 커서(Scroll / View), 콜라주 카드 위에서는 십자선과 작업 이름. 콜라주는 마우스 반대쪽으로 깊이에 따라 조금씩 움직인다
   - 회사별 보기는 책 색인 탭 모양: 회사마다 색이 다른 탭이 아래 가장자리에서 올라온다. PC 는 맞는 카드만 새 자리로 다시 흩어진다
   - '전체 한눈에 보기' 버튼: 콜라주가 다 펼쳐진 위치로 바로 이동
   - 모바일(1024px 미만): 대표 작업 5장을 겹친 카드로 아래에서 위로 넘긴 뒤(pin), 전체 목록은 카드마다 다른 방향(아래, 왼쪽, 오른쪽, 위, 멀리서)에서 들어온다. 색인 탭은 화면 아래에 붙어 따라오고, 누르면 카드 묶음이 오른쪽으로 빠지고 고른 회사 묶음이 왼쪽에서 들어온다
4. 상세 창: 카드를 누르면 그 카드 자리에서 창이 커지며 열린다. 사진은 확대된 상태에서 천천히 제자리로, 글은 흐릿하다가 한 줄씩 또렷해진다. ESC, 바깥 클릭, 닫기 버튼으로 닫고, 닫으면 누른 카드로 포커스가 돌아간다

움직임 줄이기 설정(prefers-reduced-motion)을 켠 사용자에게는 애니메이션 없이 내용만 보여 줍니다.

## 상세 창의 링크

- 링크가 열리는 작업: '사이트 보기' 링크
- 사이트가 바뀐 작업: 링크 없이 작업 내용만 (works-data.js 에 `dead: true` 또는 캡처 프로그램 결과)
- 로그인, 관리자 페이지: 링크 대신 작업 내용만

## 캡처 프로그램 쓰는 법

Node.js 18 이상이 필요합니다. `tools` 폴더에서:

```
npm install
npx playwright install chromium
npm run capture
```

- 크롬이 깔려 있으면 두 번째 줄 대신 `npm run capture -- --channel=chrome`
- 몇 개만 다시 찍기: `npm run capture -- --only=dokgong,tnjad`
- 끝나면 `images/works/` 에 캡처가, `js/works-status.js` 에 링크 결과가 생깁니다. 둘 다 커밋하면 페이지에 반영됩니다.
- 썸네일 우선순위: works-data.js 의 `thumb`(직접 고른 이미지) > 캡처 > 제목 카드
